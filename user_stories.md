# User Stories

## Doctor
- As a doctor, I want to view my appointments so that I can manage my schedule.
- As a doctor, I want to see patient records before consultation.

## Patient
- As a patient, I want to search doctors by specialty.
- As a patient, I want to book appointments online.

## Admin
- As an admin, I want to add new doctors to the system.
- As an admin, I want to manage doctor schedules.
