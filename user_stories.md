# User Stories – Smart Clinic Management System

## 👩‍⚕️ Admin User Stories

- As an **Admin**, I want to log in securely so that I can manage the clinic system.
- As an **Admin**, I want to add new doctors to the system so that patients can book appointments with them.
- As an **Admin**, I want to remove doctors from the system so that inactive doctors are no longer listed.
- As an **Admin**, I want to view all registered patients so that I can manage patient records.
- As an **Admin**, I want to view all scheduled appointments so that I can oversee clinic operations.
- As an **Admin**, I want to generate daily appointment reports by doctor so that I can track clinic performance.
- As an **Admin**, I want to view which doctor had the most patients in a given month so that I can evaluate performance.

## 🧑‍⚕️ Doctor User Stories

- As a **Doctor**, I want to log in to my portal so that I can view my appointments.
- As a **Doctor**, I want to view my daily appointment schedule so that I can prepare for patient visits.
- As a **Doctor**, I want to view patient details for each appointment so that I can provide personalized care.
- As a **Doctor**, I want to create a prescription for a patient after a consultation so that they receive the correct medications.
- As a **Doctor**, I want to view the prescription history of a patient so that I can avoid conflicting medications.
- As a **Doctor**, I want to mark an appointment as completed or cancelled so that records stay accurate.
- As a **Doctor**, I want to update my available time slots so that patients can book appointments correctly.

## 🧍 Patient User Stories

- As a **Patient**, I want to register an account so that I can access the clinic portal.
- As a **Patient**, I want to log in securely so that I can manage my appointments.
- As a **Patient**, I want to search for doctors by specialization so that I can find the right doctor.
- As a **Patient**, I want to book an appointment with a doctor so that I can receive medical attention.
- As a **Patient**, I want to view my upcoming appointments so that I can plan accordingly.
- As a **Patient**, I want to cancel an appointment so that the time slot can be freed for others.
- As a **Patient**, I want to view my prescription history so that I can keep track of my medications.
- As a **Patient**, I want to receive a confirmation of my appointment booking so that I know it was successful.
